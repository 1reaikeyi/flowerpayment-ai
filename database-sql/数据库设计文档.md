## 一、数据表总览



| 序号 | SQL                   | 说明                           |
| :--: | --------------------- | ------------------------------ |
|  1   | `employee`            | 员工信息表（店长/花艺师/客服） |
|  2   | `flower_category`     | 鲜花及节日礼盒分类表           |
|  3   | `flower`              | 鲜花单品表                     |
|  4   | `flower_detail`       | 鲜花规格表（送人对象/用途）    |
|  5   | `festival`            | 节日多花组合礼盒表             |
|  6   | `festival_detail`     | 礼盒鲜花关系表                 |
|  7   | `user`                | C 端用户信息表                 |
|  8   | `user_address`        | 收货地址簿                     |
|  9   | `user_shopping`       | 购物车表                       |
|  10  | `flower_order`        | 鲜花订单主表                   |
|  11  | `flower_order_detail` | 订单明细表                     |
|  12  | `flower_order_pay`    | 订单支付记录表                 |

------

## 二、分表详细设计

### 1. employee 员工信息表

用于存储花店后台管理员 / 员工账号信息

| 字段名        | 数据类型    | 说明      | 备注                            |
| ------------- | ----------- | --------- | ------------------------------- |
| `id`          | bigint      | 主键      | 自增，主键索引                  |
| `name`        | varchar(32) | 员工姓名  | 已修正原文档"在职部门"错误      |
| `username`    | varchar(32) | 登录账号  | 唯一索引 `idx_username`，不可空 |
| `password`    | varchar(64) | 密码      | 不可空                          |
| `avatar`      | varchar(64) | 头像      | 可空                            |
| `email`       | varchar(32) | 邮箱      | 不可空                          |
| `phone`       | varchar(11) | 手机号    | 不可空                          |
| `sex`         | varchar(2)  | 性别      | 不可空                          |
| `status`      | bigint      | 账号状态  | 默认 1；0 禁用，1 启用，不可空  |
| `create_time` | datetime    | 创建时间  | 可空                            |
| `update_time` | datetime    | 更新时间  | 可空                            |
| `create_user` | bigint      | 创建人 ID | 可空                            |
| `update_user` | bigint      | 修改人 ID | 可空                            |

- 索引：唯一索引 `idx_username(username)`

------

### 2. flower_category 鲜花及节日礼盒分类表

统一管理鲜花单品、节日礼盒、礼品三级分类

| 字段名        | 数据类型    | 说明      | 备注                                                   |
| ------------- | ----------- | --------- | ------------------------------------------------------ |
| `id`          | bigint      | 主键      | 自增主键                                               |
| `name`        | varchar(32) | 分类名称  | 唯一索引 `idx_category_name`，不可空                   |
| `type`        | bigint      | 分类类型  | **1 = 鲜花商品单只，2 = 节日商品多只，3 = 礼品**，可空 |
| `sort`        | bigint      | 排序序号  | 默认 0，不可空                                         |
| `status`      | bigint      | 启用状态  | 0 禁用，1 启用，可空                                   |
| `create_time` | datetime    | 创建时间  | 可空                                                   |
| `update_time` | datetime    | 更新时间  | 可空                                                   |
| `create_user` | bigint      | 创建人 ID | 可空                                                   |
| `update_user` | bigint      | 修改人 ID | 可空                                                   |

- 索引：唯一索引 `idx_category_name(name)`

------

### 3. flower 鲜花单品表

存储所有单支/单束鲜花基础信息

| 字段名        | 数据类型      | 说明          | 备注                               |
| ------------- | ------------- | ------------- | ---------------------------------- |
| `id`          | bigint        | 主键          | 自增主键                           |
| `name`        | varchar(32)   | 鲜花名称      | 唯一索引 `idx_flower_name`，不可空 |
| `category_id` | bigint        | 所属分类 ID   | 关联 `flower_category.id`，不可空  |
| `price`       | decimal(10,2) | 单价          | 可空                               |
| `image`       | varchar(255)  | 商品图片      | 可空                               |
| `description` | varchar(255)  | 花语/描述信息 | 可空                               |
| `status`      | bigint        | 售卖状态      | 默认 1；0 下架，1 在售，可空       |
| `create_time` | datetime      | 创建时间      | 可空                               |
| `update_time` | datetime      | 更新时间      | 可空                               |
| `create_user` | bigint        | 创建人 ID     | 可空                               |
| `update_user` | bigint        | 修改人 ID     | 可空                               |

- 索引：唯一索引 `idx_flower_name(name)`

------

### 4. flower_detail 鲜花规格表

存储鲜花的多维度规格属性（送人对象 + 适用场景）

| 字段名         | 数据类型     | 说明        | 备注                                 |
| -------------- | ------------ | ----------- | ------------------------------------ |
| `id`           | bigint       | 主键        | 自增主键                             |
| `flower_id`    | bigint       | 关联鲜花 ID | 关联 `flower.id`，不可空             |
| `spec_object`  | varchar(32)  | 送人对象    | 如：女友、母亲、朋友，可空           |
| `spec_options` | varchar(255) | 用途/场景   | 如：表白、生日、道歉，逗号分隔，可空 |

- 索引：唯一索引 `idx_flower_spec(flower_id, spec_object)`

------

### 5. festival 节日多花组合表

节日礼盒/礼品套餐基础信息

| 字段名        | 数据类型      | 说明        | 备注                                 |
| ------------- | ------------- | ----------- | ------------------------------------ |
| `id`          | bigint        | 主键        | 自增主键                             |
| `category_id` | bigint        | 所属分类 ID | 关联 `flower_category.id`，可空      |
| `name`        | varchar(32)   | 礼盒名称    | 唯一索引 `idx_festival_name`，不可空 |
| `price`       | decimal(10,2) | 礼盒价格    | 不可空                               |
| `number`      | bigint        | 鲜花总数量  | 礼盒内花朵总数，不可空               |
| `status`      | bigint        | 售卖状态    | 默认 1；0 下架，1 在售，可空         |
| `description` | varchar(255)  | 礼盒描述    | 可空                                 |
| `image`       | varchar(255)  | 礼盒图片    | 可空                                 |
| `create_time` | datetime      | 创建时间    | 可空                                 |
| `update_time` | datetime      | 更新时间    | 可空                                 |
| `create_user` | bigint        | 创建人 ID   | 可空                                 |
| `update_user` | bigint        | 修改人 ID   | 可空                                 |

- 索引：唯一索引 `idx_festival_name(name)`

------

### 6. festival_detail 礼盒鲜花关系表

礼盒内包含的具体鲜花明细（一行一条记录，支持 JOIN 查询）

| 字段名         | 数据类型     | 说明         | 备注                                                 |
| -------------- | ------------ | ------------ | ---------------------------------------------------- |
| `id`           | bigint       | 主键         | 自增主键                                             |
| `festival_id`  | bigint       | 关联礼盒 ID  | 关联 `festival.id`，可空                             |
| `flower_id`    | bigint       | 关联鲜花 ID  | 关联 `flower.id`，可空（已拆为单行存储，非逗号拼接） |
| `spec_object`  | varchar(32)  | 送人对象标注 | 该花在礼盒中的送人对象，可空                         |
| `spec_options` | varchar(255) | 用途标注     | 该花在礼盒中的用途场景，可空                         |

------

### 7. user C 端用户信息表

小程序 / Web 端普通购花用户

| 字段名        | 数据类型     | 说明     | 备注                 |
| ------------- | ------------ | -------- | -------------------- |
| `id`          | bigint       | 主键     | 自增主键             |
| `username`    | varchar(32)  | 用户昵称 | 可空                 |
| `password`    | varchar(64)  | 登录密码 | 可空                 |
| `phone`       | varchar(11)  | 手机号   | 可空                 |
| `sex`         | varchar(2)   | 性别     | 可空                 |
| `id_number`   | varchar(18)  | 身份证号 | 可空                 |
| `avatar`      | varchar(500) | 头像链接 | 可空                 |
| `create_time` | datetime     | 注册时间 | 可空                 |
| `status`      | bigint       | 用户状态 | 0 注销，1 启用，可空 |

------

### 8. user_address 收货地址簿

用户多收货地址存储（用于鲜花配送）

| 字段名          | 数据类型     | 说明           | 备注                       |
| --------------- | ------------ | -------------- | -------------------------- |
| `id`            | bigint       | 主键           | 自增主键                   |
| `user_id`       | bigint       | 所属用户 ID    | 关联 `user.id`，不可空     |
| `consignee`     | varchar(50)  | **收花人**姓名 | 原"收货人"已改为"收花人"   |
| `sex`           | varchar(2)   | 收花人性别     | 可空                       |
| `phone`         | varchar(11)  | 联系手机号     | 不可空                     |
| `province_code` | varchar(12)  | 省份区划编码   | 可空                       |
| `province_name` | varchar(32)  | 省份名称       | 可空                       |
| `city_code`     | varchar(12)  | 城市区划编码   | 可空                       |
| `city_name`     | varchar(32)  | 城市名称       | 可空                       |
| `district_code` | varchar(12)  | 区县区划编码   | 可空                       |
| `district_name` | varchar(32)  | 区县名称       | 可空                       |
| `detail`        | varchar(200) | 详细门牌号     | 可空                       |
| `label`         | varchar(100) | 地址标签       | 家 / 公司 / 学校，可空     |
| `is_default`    | bigint       | 是否默认地址   | 默认 0；0 否，1 是，不可空 |

------

### 9. user_shopping 购物车表

用户未下单前的临时选购数据

| 字段名        | 数据类型      | 说明           | 备注                   |
| ------------- | ------------- | -------------- | ---------------------- |
| `id`          | bigint        | 主键           | 自增主键               |
| `name`        | varchar(32)   | 商品名称       | 鲜花或礼盒名称，可空   |
| `image`       | varchar(255)  | 商品图片       | 可空                   |
| `user_id`     | bigint        | 用户 ID        | 关联 `user.id`，不可空 |
| `flower_id`   | bigint        | 鲜花单品 ID    | 选购单品时赋值，可空   |
| `festival_id` | bigint        | 节日礼盒 ID    | 选购礼盒时赋值，可空   |
| `number`      | bigint        | 选购数量       | 默认 1，不可空         |
| `amount`      | decimal(10,2) | 小计金额       | 不可空                 |
| `create_time` | datetime      | 加入购物车时间 | 可空                   |

------

### 10. flower_order 订单主表

订单主表，存储订单整体状态、收货配送信息

| 字段名                    | 数据类型     | 说明             | 备注                                                         |
| ------------------------- | ------------ | ---------------- | ------------------------------------------------------------ |
| `id`                      | bigint       | 主键             | 自增主键                                                     |
| `status`                  | bigint       | 订单状态         | **1 用户下单 → 2 确认支付 → 3 商家制作 → 4 快递员取货 → 5 配送中 → 6 已送达 → 7 系统自动确认 → 8 已取消**，不可空 |
| `user_id`                 | bigint       | 下单用户 ID      | 关联 `user.id`，不可空                                       |
| `username`                | varchar(32)  | 用户名称         | 冗余字段，可空                                               |
| `consignee`               | varchar(32)  | 收花人           | 冗余字段，可空                                               |
| `phone`                   | varchar(11)  | 收花人手机号     | 可空                                                         |
| `address_id`              | bigint       | 地址 ID          | 关联 `user_address.id`，不可空                               |
| `address`                 | varchar(255) | 完整配送地址     | 冗余字段，可空                                               |
| `pay_status`              | bigint       | 支付状态         | 默认 0；关联 `flower_order_pay`，0 未支付，1 已支付，2 退款  |
| `remark`                  | varchar(100) | 备注信息         | **可存 AI 生成的贺卡文案**，可空                             |
| `delivery_type`           | bigint       | 配送方式         | **0 预约配送，1 立即送出**，可空                             |
| `delivery_date`           | date         | **预约配送日期** | 鲜花核心字段，可空                                           |
| `start_delivery_time`     | datetime     | 配送开始时间     | 可空                                                         |
| `estimated_delivery_time` | datetime     | 预计送达时间     | 可空                                                         |
| `delivery_time`           | datetime     | 实际送达时间     | 可空                                                         |
| `create_time`             | datetime     | 创建时间         | 可空                                                         |
| `update_time`             | datetime     | 更新时间         | 可空                                                         |

------

### 11. flower_order_detail 订单明细表

下单商品明细（鲜花单品 / 节日礼盒）

| 字段名        | 数据类型      | 说明         | 备注                           |
| ------------- | ------------- | ------------ | ------------------------------ |
| `id`          | bigint        | 主键         | 自增主键                       |
| `order_id`    | bigint        | 主订单 ID    | 关联 `flower_order.id`，不可空 |
| `name`        | varchar(32)   | 商品名称     | 冗余字段，可空                 |
| `image`       | varchar(255)  | 商品图片     | 冗余字段，可空                 |
| `flower_id`   | bigint        | 鲜花单品 ID  | 购买单品时赋值，可空           |
| `festival_id` | bigint        | 节日礼盒 ID  | 购买礼盒时赋值，可空           |
| `number`      | bigint        | 购买数量     | 默认 1，不可空                 |
| `amount`      | decimal(10,2) | 单条明细金额 | 不可空                         |
| `wrap_fee`    | bigint        | 礼盒包装费   | 可空（原打包费/餐具已删除）    |

------

### 12. flower_order_pay 订单支付记录表

独立支付流水表，存储支付、退款、取消相关记录

| 字段名          | 数据类型      | 说明            | 备注                                         |
| --------------- | ------------- | --------------- | -------------------------------------------- |
| `id`            | bigint        | 主键 ID         | 自增主键                                     |
| `order_id`      | bigint        | 关联订单 ID     | 关联 `flower_order.id`，可空                 |
| `order_time`    | datetime      | 下单时间        | 不可空                                       |
| `pay_method`    | bigint        | 支付方式        | 默认 1；1 微信，2 支付宝，不可空             |
| `pay_status`    | bigint        | 支付状态        | 默认 0；0 未支付，1 已支付，2 已退款，不可空 |
| `checkout_time` | datetime      | 实际支付时间    | 可空                                         |
| `amount`        | decimal(10,2) | 实收总金额      | 不可空                                       |
| `remark`        | varchar(100)  | 支付备注        | 可空                                         |
| `cancel_reason` | varchar(255)  | 订单取消原因    | 可空                                         |
| `cancel_time`   | datetime      | 取消 / 退款时间 | 可空                                         |
| `create_time`   | datetime      | 记录创建时间    | 可空                                         |
| `update_time`   | datetime      | 记录更新时间    | 可空                                         |
| `create_user`   | bigint        | 操作创建人 ID   | 可空                                         |
| `update_user`   | bigint        | 操作修改人 ID   | 可空                                         |
