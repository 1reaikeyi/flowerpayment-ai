## 一、数据表总览

共 15 张表，覆盖员工管理、商品（鲜花单品 / 节日礼盒）、用户、购物车、订单支付及 AI 对话等模块。

| 序号 | SQL                   | 说明                            |
| :--: | --------------------- | ------------------------------- |
|  1   | `employee`            | 员工信息表（店长/店员/客服）    |
|  2   | `flower_category`     | 鲜花及节日礼盒分类表            |
|  3   | `flower_shop`         | 鲜花单品表                      |
|  4   | `flower_detail`       | 鲜花规格表（送人对象/用途）     |
|  5   | `festival             | 多花组合表                      |
|  6   | `festival_detail`     | 多花组合规格表（送人对象/用途） |
|  7   | `user`                | C 端用户信息表                  |
|  8   | `user_address`        | 收货地址簿                      |
|  9   | `user_shopping`       | 购物车表                        |
|  10  | `flower_order`        | 鲜花订单主表                    |
|  11  | `flower_order_detail` | 订单明细表                      |
|  12  | `flower_order_pay`    | 订单支付记录表                  |
|  13  | `chat_session`        | AI 对话会话表                   |
|  14  | `chat_record`         | AI 对话记录表                   |

------

## 二、分表详细设计

### 1. employee 员工信息表

用于存储花店后台管理员 / 员工账号信息。

| 字段名        | 数据类型    | 说明      | 备注                            |
| ------------- | ----------- | --------- | ------------------------------- |
| `id`          | bigint      | 主键      | 自增，主键索引                  |
| `work`        | varchar(32) | 工作岗位  | 如：店长/店员/客服，不可空      |
| `username`    | varchar(32) | 登录账号  | 唯一索引 `idx_username`，不可空 |
| `password`    | varchar(64) | 密码      | 不可空                          |
| `avatar`      | varchar(64) | 头像      | 可空                            |
| `email`       | varchar(32) | 邮箱      | 不可空                          |
| `phone`       | varchar(11) | 手机号    | 不可空                          |
| `sex`         | varchar(2)  | 性别      | 不可空                          |
| `status`      | bigint      | 账号状态  | 默认 1；0 禁用，1 启用，不可空  |
| `create_time` | datetime    | 创建时间  | 可空                            |
| `update_time` | datetime    | 更新时间  | 可空                            |
| `create_user` | bigint      | 创建人 ID | 可空                            |
| `update_user` | bigint      | 修改人 ID | 可空                            |

- 索引：唯一索引 `idx_username(username)`
- 表字符集：`utf8mb4`（表级 `collate = utf8mb4_bin`）

------

### 2. flower_category 鲜花及节日礼盒分类表

统一管理鲜花单品、节日礼盒等分类。

| 字段名        | 数据类型    | 说明      | 备注                                                   |
| ------------- | ----------- | --------- | ------------------------------------------------------ |
| `id`          | bigint      | 主键      | 自增主键                                               |
| `name`        | varchar(32) | 分类名称  | 唯一索引 `idx_category_name`，不可空                   |
| `type`        | bigint      | 分类类型  | **1 = 鲜花商品单只，2 = 节日商品多只，3 = 其他**，可空 |
| `sort`        | bigint      | 排序序号  | 默认 0，不可空                                         |
| `status`      | bigint      | 启用状态  | 0 禁用，1 启用，可空                                   |
| `create_time` | datetime    | 创建时间  | 可空                                                   |
| `update_time` | datetime    | 更新时间  | 可空                                                   |
| `create_user` | bigint      | 创建人 ID | 可空                                                   |
| `update_user` | bigint      | 修改人 ID | 可空                                                   |

- 索引：唯一索引 `idx_category_name(name)`
- 表字符集：`utf8mb4`

------

### 3. flower_shop 鲜花单品表

存储所有单支 / 单束鲜花基础信息。SQL 中表名为 `flower_shop`。

| 字段名        | 数据类型      | 说明          | 备注                               |
| ------------- | ------------- | ------------- | ---------------------------------- |
| `id`          | bigint        | 主键          | 自增主键                           |
| `category_id` | bigint        | 所属分类 ID   | 关联 `flower_category.id`，不可空  |
| `name`        | varchar(32)   | 鲜花名称      | 唯一索引 `idx_flower_name`，不可空 |
| `color`       | varchar(8)    | 颜色          | 可空                               |
| `price`       | decimal(10,2) | 单价          | 可空                               |
| `image`       | varchar(255)  | 商品图片      | 可空                               |
| `description` | varchar(255)  | 花语/描述信息 | 可空                               |
| `status`      | bigint        | 售卖状态      | 默认 1；0 下架，1 在售，可空       |
| `create_time` | datetime      | 创建时间      | 可空                               |
| `update_time` | datetime      | 更新时间      | 可空                               |
| `create_user` | bigint        | 创建人 ID     | 可空                               |
| `update_user` | bigint        | 修改人 ID     | 可空                               |

- 索引：唯一索引 `idx_flower_name(name)`
- 表字符集：`utf8mb4`

------

### 4. flower_detail 鲜花规格表

存储鲜花的多维度规格属性（送人对象 + 适用场景）。

| 字段名        | 数据类型     | 说明        | 备注                                 |
| ------------- | ------------ | ----------- | ------------------------------------ |
| `id`          | bigint       | 主键        | 自增主键                             |
| `flower_id`   | bigint       | 关联鲜花 ID | 关联 `flower_shop.id`，不可空        |
| `spec_object` | varchar(32)  | 送人对象    | 如：女友、母亲、朋友，可空           |
| `spec_option` | varchar(255) | 用途/场景   | 如：表白、生日、道歉，逗号分隔，可空 |

- 索引：普通索引 `idx_flower_id(flower_id)`
- 表字符集：`utf8mb4`

------

### 5. festival   多花组合表

节日多花组合 / 礼品套餐基础信息。

| 字段名        | 数据类型      | 说明        | 备注                                 |
| ------------- | ------------- | ----------- | ------------------------------------ |
| `id`          | bigint        | 主键        | 自增主键                             |
| `category_id` | bigint        | 所属分类 ID | 关联 `flower_category.id`，可空      |
| `name`        | varchar(32)   | 礼盒名称    | 唯一索引 `idx_festival_name`，不可空 |
| `price`       | decimal(10,2) | 礼盒价格    | 不可空                               |
| `number`      | bigint        | 鲜花总数量  | 礼盒内花朵总数，不可空               |
| `status`      | bigint        | 售卖状态    | 默认 1；0 下架，1 在售，可空         |
| `description` | varchar(255)  | 礼盒描述    | 可空                                 |
| `image`       | varchar(255)  | 礼盒图片    | 可空                                 |
| `create_time` | datetime      | 创建时间    | 可空                                 |
| `update_time` | datetime      | 更新时间    | 可空                                 |
| `create_user` | bigint        | 创建人 ID   | 可空                                 |
| `update_user` | bigint        | 修改人 ID   | 可空                                 |

- 索引：唯一索引 `idx_festival_name(name)`
- 表注释：`节日多花组合`；表字符集：`utf8mb4`

------

### 6. festival_detail   多花组合规格表

礼盒内包含的具体鲜花明细（一行一条记录，支持 JOIN 查询）。

| 字段名        | 数据类型     | 说明         | 备注                         |
| ------------- | ------------ | ------------ | ---------------------------- |
| `id`          | bigint       | 主键         | 自增主键                     |
| `festival_id` | bigint       | 关联礼盒 ID  | 关联 `festival.id`，可空     |
| `flower_id`   | bigint       | 关联鲜花 ID  | 关联 `flower_shop.id`，可空  |
| `spec_object` | varchar(32)  | 送人对象标注 | 该花在礼盒中的送人对象，可空 |
| `spec_option` | varchar(255) | 用途标注     | 该花在礼盒中的用途场景，可空 |

- 索引：普通索引 `idx_festival_id(festival_id)`
- 索引：普通索引 `idx_flower_id(flower_id)`
- 表字符集：`utf8mb4`

------

### 13. chat_session AI 对话会话表

存储 AI 聊天的会话（一次咨询 = 一个 session）。

| 字段名        | 数据类型     | 说明     | 备注                                                         |
| ------------- | ------------ | -------- | ------------------------------------------------------------ |
| `id`          | bigint       | 主键     | 主键索引，`create_time` 默认 `CURRENT_TIMESTAMP`，`update_time` 自动更新 |
| `session_id`  | varchar(32)  | 会话 ID  | 业务会话标识，不可空                                         |
| `user_id`     | bigint       | 用户 ID  | 关联 `user.id`，默认 0，不可空                               |
| `title`       | varchar(100) | 会话标题 | 可空                                                         |
| `create_time` | datetime     | 创建时间 | 默认 `CURRENT_TIMESTAMP`，不可空                             |
| `update_time` | datetime     | 更新时间 | 默认 `CURRENT_TIMESTAMP` 且 `ON UPDATE` 自动更新，不可空     |

- 索引：普通索引 `session_id_index(session_id)`
- 索引：普通索引 `update_time_index(update_time)`
- 索引：普通索引 `user_id_index(user_id)`

------

### 14. chat_record AI 对话记录表

存储 AI 对话的单条消息记录（请求 / 响应）。

| 字段名            | 数据类型     | 说明     | 备注                                                         |
| ----------------- | ------------ | -------- | ------------------------------------------------------------ |
| `id`              | bigint       | 主键     | 主键索引，`create_time` 默认 `CURRENT_TIMESTAMP`，`update_time` 自动更新 |
| `conversation_id` | varchar(100) | 对话 ID  | 归属的会话标识，不可空                                       |
| `data`            | text         | 对话数据 | 请求/响应内容（JSON 等），可空                               |
| `create_time`     | datetime     | 创建时间 | 默认 `CURRENT_TIMESTAMP`，不可空                             |
| `update_time`     | datetime     | 更新时间 | 默认 `CURRENT_TIMESTAMP` 且 `ON UPDATE` 自动更新，不可空     |

- 索引：普通索引 `conversation_id_index(conversation_id)`
- 索引：普通索引 `create_time_index(create_time)`

> 说明：`chat_session`（会话）与 `chat_record`（消息）为一对多关系，通过 `chat_record.conversation_id` 关联 `chat_session.session_id`。
